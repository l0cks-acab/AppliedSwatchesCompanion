# Changelog

## 0.2.0

- Lens modules: cards that install into the lens from a module panel on the Lens screen, or by right-clicking them onto the lens.
- Recolour Module: swap a block (with its stairs, slabs and walls) across the region, paid for from ME, with undo.
- Gradient Module: build a ramp of 3 to 9 blocks between two colours from ME, ready for the terminal or a Swatch Applicator.
- Focal Point Module: outlines plain, light areas that could use an accent and marks where it would go.
- Surroundings Module: a Terrain score for how the build's colours fit the land around it.
- Stack counts on the Lens screen use AE2's small numbers.

## 0.1.2

- Built against AppliedSwatches 0.2.3 (redesigned Swatch Applicator, Creative Swatch Cell), which is now the minimum version.

## 0.1.1

- Save theme now asks for a name first (prefilled with the scan time). An existing theme with the same name is kept and the new one gets a _2 suffix.

## 0.1.0

First release.

- Swatch Lens: select a region, link to a Swatch or Theme Terminal, and scan.
- Scores for contrast, visual weight balance, palette (60-30-10) and similarity (orphan blocks), plus an overall score.
- Visual weight heatmap with orphan block outlines.
- Accent suggestions (Harmony: shades, tints, muted tones and bridging greys of the build's palette; Contrast: complementary) from the linked ME network: send them to the terminal, load them into a Swatch Applicator, or save them as a theme.
